# Practical 2

This practical examines floating-point arithmetic and numerical precision.

## Conversion.c

This program converts an integer to a floating-point representation and binary representation, and counts the number of binary digits.

Compile:

gcc -o Conversion Conversion.c -lm

Run:

./Conversion

## Sum.c

This program calculates the harmonic sum in forward and reverse order to demonstrate floating-point rounding effects.

Compile:

gcc -o Sum Sum.c

Run:

./Sum

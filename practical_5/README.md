# Practical 5

This practical covers pointers and user input in C.

## input.c

This program uses scanf to read an integer and a double.

Compile:
gcc -o input input.c

Run:
./input

## fibonacci.c

This program calculates the Fibonacci series using a function and pointers.

Compile:
gcc -o fibonacci fibonacci.c

Run:
./fibonacci

## artanh.c

This program calculates arctanh(x) using a Maclaurin series and logarithms.

The results are stored in two arrays and compared.

Compile:
gcc -o artanh artanh.c -lm

Run:
./artanh

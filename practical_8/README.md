
# Practical 8

This practical covers iterative and recursive functions
using the Euclidean algorithm.

## practical8.c

This program calculates the Greatest Common Divisor
(GCD) of two positive integers.

Two methods are implemented:

1. Iterative method using a while loop.
2. Recursive method using a function that calls itself.

The program prints the results of both methods.

## Compile

gcc -Wall -o practical8 practical8.c

## Run

./practical8

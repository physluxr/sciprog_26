# Practical 4

This practical uses arrays and functions in C.

The program calculates tan(x) from 0 to 60 degrees
in steps of 5 degrees and stores the results in a global array.

It also uses a function to calculate the integral of tan(x)
using the trapezoidal rule.

## Compile

gcc -Wall -o practical4 practical4.c -lm

## Run

./practical4
